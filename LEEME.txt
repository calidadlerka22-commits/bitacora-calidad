BITÁCORA INTELIGENTE DE RECLAMACIONES — PAQUETE PWA

CONTENIDO
- index.html: aplicación web de reclamaciones, historial, catálogo SKU y análisis de hasta 4 imágenes.
- manifest.webmanifest: configuración de instalación PWA.
- service-worker.js: caché de archivos principales para modo instalable.
- icons/: iconos SVG de 192 y 512 px.
- .github/workflows/deploy.yml: publicación automatizada con GitHub Pages.

PUBLICAR LA APLICACIÓN
1. En GitHub abre Settings > Pages.
2. En Build and deployment, selecciona Source: GitHub Actions.
3. Confirma que Actions tenga permisos para publicar Pages en Settings > Actions > General, si GitHub lo solicita.
4. En Actions, ejecuta el flujo "Deploy Bitácora PWA" o espera el siguiente commit.
5. Cuando termine en verde, abre la URL que muestra Settings > Pages. La dirección será HTTPS.

INSTALAR EN WINDOWS / PC
1. Abre la URL HTTPS en Chrome o Microsoft Edge.
2. Pulsa el icono Instalar en la barra de direcciones, o menú > Instalar Bitácora Calidad.

INSTALAR EN ANDROID
1. Abre la URL HTTPS en Chrome.
2. Menú ⋮ > Instalar aplicación o Agregar a pantalla principal.

INSTALAR EN IPHONE
1. Abre la URL HTTPS en Safari.
2. Compartir > Agregar a pantalla de inicio.

IMPORTANTE SOBRE DATOS
La versión actual guarda los registros en localStorage del navegador/dispositivo. No sincroniza automáticamente entre PC y teléfono. Exporta respaldos JSON con frecuencia. Para uso multiusuario y sincronización se requiere integrar autenticación y una base de datos en la nube.

OCR
El motor OCR se carga desde una biblioteca externa (requiere conexión a internet para cargarlo la primera vez). Revisa visualmente los SKU detectados antes de emitir indicaciones preventivas.
