BITÁCORA INTELIGENTE DE RECLAMACIONES — APLICACIÓN INSTALABLE

Incluye:
- index.html: aplicación con el botón Nueva búsqueda.
- manifest.webmanifest: nombre e iconos de instalación.
- service-worker.js: caché para abrir la app como PWA tras la primera carga.
- icons/: iconos para PC y celulares.

IMPORTANTE: Para instalarla como aplicación PWA, primero debe publicarse en una dirección HTTPS. Abrir index.html directamente desde el disco permite usarla como página, pero no habilita la instalación PWA.

PUBLICAR GRATIS CON GITHUB PAGES
1. Descomprime el ZIP.
2. Crea un repositorio en GitHub, por ejemplo: bitacora-calidad.
3. Sube TODOS los archivos y la carpeta icons a la raíz del repositorio.
4. En Settings > Pages, activa publicación desde la rama main y carpeta / (root).
5. Espera la URL HTTPS que proporciona GitHub Pages.

INSTALAR EN PC
1. Abre la URL HTTPS en Chrome o Edge.
2. Pulsa el icono Instalar aplicación de la barra de direcciones o abre el menú y elige Instalar Bitácora Calidad.

INSTALAR EN ANDROID
1. Abre la URL HTTPS en Chrome.
2. Menú ⋮ > Instalar aplicación o Agregar a pantalla principal.

INSTALAR EN IPHONE
1. Abre la URL HTTPS en Safari.
2. Compartir > Agregar a pantalla de inicio.

DATOS Y OCR
La aplicación guarda los registros en localStorage del navegador y dispositivo actual. No sincroniza automáticamente los datos entre PC y celular; para eso hace falta una base de datos en la nube.
El motor OCR se carga desde una biblioteca externa, por lo que el primer análisis requiere internet. No se garantiza OCR completamente sin conexión.
